# PS1-Style Low-Poly Archer Girl

Интерактивный 3D-персонаж в стиле PlayStation 1, созданный с использованием Three.js.

![PS1 Archer Girl](https://img.shields.io/badge/Three.js-r160+-blue.svg)
![React](https://img.shields.io/badge/React-18+-61dafb.svg)
![Vite](https://img.shields.io/badge/Vite-6+-646cff.svg)

## 🎮 Особенности

- **Аутентичная PS1-эстетика**: низкое разрешение, vertex snapping, плоское затенение
- **Интерактивный просмотр**: вращение, масштабирование, панорамирование со всех сторон
- **3 позы**: Idle (покой), Aim (прицеливание), Draw (натяжение тетивы)
- **3 цветовые палитры**: Forest (лес), Desert (пустыня), Night (ночь)
- **Ретро UI**: интерфейс в стиле PS1 с беvel-кнопками
- **Runtime self-checks**: автоматическая валидация геометрии

## 🎯 Управление

### Камера
- **Левая кнопка мыши + перетаскивание**: вращение камеры
- **Колесо мыши**: масштабирование
- **Правая кнопка мыши + перетаскивание**: панорамирование

### UI элементы
- **Auto-Rotate**: автоматическое вращение персонажа
- **Wireframe**: режим каркасного отображения
- **Pose**: выбор позы (Idle / Aim / Draw)
- **Palette**: выбор цветовой палитры (Forest / Desert / Night)
- **View**: предустановленные ракурсы (Front / Side / Back / Top / Reset)
- **PS1 FX**: включение/выключение PS1-эффектов (vertex snap + пикселизация)
- **PS1 FPS**: ограничение частоты обновления поз до ~12 Hz
- **Res**: разрешение рендера (240p / 360p / 480p)
- **Screenshot**: сохранение скриншота в PNG

## 🎨 PS1-эффекты

### Vertex Snapping
Квантование позиций вершин к пиксельной сетке через `onBeforeCompile` шейдеров.

### Color Quantization
5-битное квантование цвета (32 оттенка на канал) для характерной цветовой деградации.

### Low Resolution
Рендер в разрешении ~240p-480p с апскейлом через CSS `image-rendering: pixelated`.

### Flat Shading
Все материалы используют `flatShading: true` для характерных граней.

## 🔍 Runtime Self-Checks

Система автоматически проверяет:

1. **HOOD_SIT**: капюшон правильно сидит на голове
2. **HOOD_COVER**: капюшон полностью покрывает голову
3. **HOOD_CENTER**: капюшон центрирован
4. **FACE_OPEN**: лицо видно из-под капюшона
5. **GRIP_WOOD**: рука держит деревянную рукоять лука
6. **LEFT_HAND_STRING_CLEAR**: рука не касается тетивы
7. **STRING_BEHIND_WOOD**: тетива за луком

Результаты выводятся в консоль браузера (F12).

## 🎯 Технические детали

### Ограничения геометрии
- ~1000 треугольников на персонажа
- Все геометрии процедурные (без внешних моделей)
- Все текстуры генерируются на canvas (64x64)

### Оптимизация
- `renderer.setPixelRatio(1)` - фиксированный pixel ratio
- `antialias: false` - без сглаживания
- `flatShading: true` - плоское затенение
- NearestFilter для текстур
- Fog для имитации draw distance
